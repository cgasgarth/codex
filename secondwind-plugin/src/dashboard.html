How these estimates work

Token counts use cl100k and include resent tool outputs and retries. They estimate savings; they are not billing totals.

API equivalent at standard uncached input prices. OpenAI uses short context (≤272k). Cache discounts, cache writes, fast mode, long-context and regional premiums are excluded. Unpriced models are excluded from the USD total. This does not reduce your subscription bill.

Rewrite time includes JSON parsing, compressor wait, compression, and JSON encoding for each changed request. Model response time is excluded.
